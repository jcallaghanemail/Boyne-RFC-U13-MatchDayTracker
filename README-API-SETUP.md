# Boyne RFC U13 shared storage API

## Upload these files
Copy the `api` folder and `.gitignore` to the root of the GitHub repository, beside `index.html`.

## Update the Azure Static Web Apps workflow
In `.github/workflows/<your-existing-workflow>.yml`, set:

```yaml
app_location: "/"
api_location: "api"
output_location: ""
```

Keep the deployment-token secret name already generated by the working Static Web App.

## Configure Azure application settings
In the Azure portal, open the Static Web App and add these environment/application settings:

- `PITCHSIDE_STORAGE_CONNECTION_STRING`: connection string from the Boyne data Storage Account
- `PITCHSIDE_TABLE_NAME`: `PitchsideData`
- `PITCHSIDE_PARTITION_KEY`: `boyne-u13`

Do not put the connection string in `index.html`, GitHub source files, or a GitHub commit.

## Test after deployment
Open:

`https://<your-static-web-app-host>/api/store?key=test`

Expected response before any value is stored:

```json
{"value":null}
```

## Important
This API is initially anonymous so it can be tested. Before real parent/player data is used, add Static Web Apps authentication and coach/parent authorisation rules.
